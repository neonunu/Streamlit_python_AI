# D_정보공개청구_회신정리

청구 4건 → 회신 12곳 (자료 11곳, 달서구는 첨부 누락 → 재요청). 원본은 `데이터/정보공개청구/` 폴더 (파일명 = 접수번호_기관). 회신 내용은 `대구경북_발달재활_제공기관_정리.csv`(서비스영역·운영요일·운영시간 열, 235곳)와 `A_공백표.csv`(대기자·실이용자 열)에 합쳐 둠.

## 제안서에 쓸 것

- **치료 분야·운영시간은 전자바우처에 없다:** 사보원 정보부존재 결정 → 1번 배경
- **그 정보는 지자체에 있다:** 경북도 170곳 운영 요일·시간·서비스 영역, 대구 동구·서구·남구·달성군 서비스 영역 → 6번 현장 적용, 3번 추정값 검증
- **예산 대기자(복지부 정의: 예산 부족으로 그해 지원 못 받은 사람):** 달성 131, 남구 41, 수성 28명(그중 장애 미등록 9세 미만 25명), 동구·북구·군위 0명 / 경북 232명(경주 82, 경산 66) → 2번
- **이용자 증가(사보원):** 대구 5,532 → 6,963명, 경북 6,321 → 6,961명 (2024 → 2026.9) → 1번
- **군위군:** 관내 제공기관 "미해당" → 군위 '확인 필요' 근거

## 주의

- 복지부 2026년 표는 칸이 섞여 있어 쓰지 않는다. 구·군 대기자는 기준 시점이 달라 더하지 않는다.
- 사보원 기관 목록 513곳 ≠ 팀 CSV 377곳, 북구 회신 34곳 ≠ CSV 38곳 → A가 차이 확인.
- 북구·중구 원본 엑셀은 매크로 바이러스 흔적이 있어 삭제하고 md·csv로 옮김.
