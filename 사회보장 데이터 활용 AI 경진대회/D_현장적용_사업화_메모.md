## 1. 단계별 적용

| 단계 | 누가 (협력 대상) | 무엇을 | 운영 방식 | 근거 |
| --- | --- | --- | --- | --- |
| **1단계: 대구·경북 시범** | 우리 팀 + 대구 장애인부모회, 대구시·구청 바우처 담당 부서 | 바우처 기관 377곳으로 부모용 후보 비교·확인 질문, 구청용 공백지도 운영 | 부모 서비스는 무료. 부모가 전화로 확인한 결과(운영시간·대기 등)를 날짜와 함께 저장해 다음 부모의 비교표에 반영 | 공백 분석 결과(기관 없음 2곳, 1곳뿐 3곳), AI 시험 3건 |
| **2단계: 사보원·지자체 연계** | 한국사회보장정보원(전자바우처), 시·도·시군구 | 전자바우처 포털·앱에 후보 비교·확인 질문 기능을 붙이는 방안 제안. 기관이 서비스 영역·운영 요일·시간을 직접 입력하는 칸 추가 제안 | 지자체가 이미 가진 기관 정보를 표준 양식으로 모아 연결 | 사보원 회신: 서비스 영역·운영시간은 전자바우처에 **없음**. 경북도는 170곳의 운영 요일·시간·서비스 영역을, 대구 동구·서구·남구·달성군은 서비스 영역을 **보유** |
| **3단계: 다른 돌봄 영역 확장** | 보건복지부, 다른 바우처 사업 담당 | 같은 엔진(조건 추출 → 후보 비교 → 확인/추정 표시 → 확인 질문)을 언어발달지원 바우처, 노인 장기요양기관 탐색 등에 적용 가능 | 대상 데이터만 바꿔 연결 (예: 국민건강보험공단 장기요양기관 검색 API) | 엔진이 특정 사업에 묶여 있지 않음 |

## 2. 지자체가 쓸 수 있는 곳

- **기관 지정 근거:** 기관이 없거나 1곳뿐인 지역(청송·울릉, 봉화·영덕·의성)을 데이터로 보여 준다.
- **예산 배분 근거:** 예산 대기자가 지역마다 크게 다르다 (2026년 대구 달성군 131명, 남구 41명 / 동구·북구 0명. 경북 경주 82명, 경산 66명 / 포항·구미 0명).
- **수요 변화:** 최근 추세가 이어지면 2029년 대구·경북 발달장애 아동은 약 8,400명으로 추정된다(현재 7,172명). 이용자도 2024→2026년 대구 5,532 → 6,963명으로 늘었다(사보원 회신).

## 3. 사업화 (제안)

| 대상 | 주는 것 | 비용 구조 (제안) |
| --- | --- | --- |
| 부모 | 후보 비교, 확인 질문, 첫 상담 체크리스트 | 무료 |
| 한국사회보장정보원 | 전자바우처 포털·앱에 붙일 기능 | 시스템 구축 용역 형태로 제안 |
| 시·군·구 | 공백지도·추세·부모 "조건에 맞는 곳 없음" 요청 집계 대시보드 | 지자체 구독 형태로 제안 |

- 수익보다 **공공 서비스 탑재**가 목표다. 민간 광고·기관 유료 노출은 받지 않는다 (추천의 중립성).

## 4. "민간 앱이 이미 있는데 왜 우리냐"

| 질문 | 답 |
| --- | --- |
| Tio·그로우매치와 뭐가 다른가 | 민간 앱은 전문가·치료사 **개인** 매칭이 중심이다. 우리는 **바우처 등록 기관 377곳 전체**를 공공데이터로 다루고, 모르는 정보는 숨기지 않고 확인 질문으로 바꾼다. 그로우매치 경북 목록에서 우리 바우처 기관과 이름이 같은 106곳 중 바우처 표시는 29곳뿐이었다 (2026-11-07 확인) |
| 개인정보는 | 치료사 개인정보를 쓰지 않는다. 그로우매치는 치료사 동의 없는 정보 게시 문제로 복지부가 검토에 들어갔다는 보도가 있다 (의학신문 2026-11-07). 부모에게서도 이름·주민번호·상세 진단명을 받지 않는다 |
| 왜 공공이 해야 하나 | 치료 분야·운영시간 정보는 전자바우처에 없고 지자체에 흩어져 있다(정보공개 회신). 이것을 모을 수 있는 건 바우처를 운영하는 공공기관이다. 구청용 공백 분석도 민간 앱에는 없다 |
| 민간과 경쟁하나 | 경쟁보다 협력이 가능하다. 공공 기관 정보를 표준화하면 민간 서비스도 정확한 바우처 정보를 쓸 수 있다 |

## 5. 위험과 대응

| 위험 | 대응 |
| --- | --- |
| 부모 확인 정보가 오래됨 | 날짜를 붙이고 일정 기간이 지나면 "다시 확인" 표시 |
| 특정 기관 쏠림 | 품질등급을 부모 화면에 보여주지 않고, 대기가 길다고 확인된 기관이 몰리면 조건이 비슷한 다른 기관을 함께 보여줌 |
| AI가 없는 정보를 만들어 냄 | 데이터에 없는 항목은 `[확인 필요]`. 시험 3건에서 운영시간·대기를 지어낸 문장 0개 (B 시험) |
| 기관 입력 부담 | 지자체가 이미 가진 정보를 먼저 연결하고, 기관 직접 입력은 선택으로 |

## 6. 제안서 6번 문장 초안

> 1단계로 대구·경북 바우처 기관 377곳을 대상으로 장애인부모회·구청과 시범 운영합니다. 2단계로 한국사회보장정보원 전자바우처 포털에 후보 비교·확인 질문 기능을 붙이는 방안을 제안합니다. 정보공개청구 결과, 기관의 서비스 영역과 운영시간은 전자바우처 시스템에는 없지만 경북도와 대구 일부 구·군은 이미 관리하고 있었습니다. 이 정보를 표준 양식으로 모으면 전국으로 확장할 수 있습니다. 3단계로 같은 엔진을 언어발달지원 바우처와 노인 장기요양기관 탐색 등 다른 돌봄 영역에 적용할 수 있습니다. 부모에게는 무료로 제공하고, 사보원 시스템 구축과 지자체 공백 대시보드로 운영 재원을 마련하는 방식을 제안합니다.
