## 1. 시험 목적과 고정 채점 기준

부모 글에서 조건을 정확하게 추출하는지, **CSV에 실제 등록된 기관만** 안내하는지, **같은 동 → 같은 시군구** 순서로 탐색하는지, **[확인됨] / [추정] / [확인 필요]**를 알맞게 표시하는지, 부모가 기관에 전화해 확인할 질문을 만드는지, **CSV·부모 글에 없는 내용을 사실로 단정하는지** 검사한다. **진단이나 치료 적합성 자체를 입증하는 시험은 아니다.**

|---|---:|---|
| 조건 정확도 | 5점 | 나이·부모가 직접 말한 치료영역(미언급 시 `전문가 상담을 통해 치료영역 확인 필요`)·아이 특성·가능 시간·지역을 각각 정확히 추출하면 1점 |

**총 배점: 사례당 17점 × 3건 = 51점.** `지어낸 문장 수`는 별도 기록하고 51점에서 추가 감점하지 않는다. 새 배점을 만들지 않고 고정 기준을 그대로 적용한다. 기존 48점 기록에서 발견된 전화번호 상태 표시 오채점은 4-2절의 근거로 정정한다.

### 별도 집계의 판정 방식

- **집계:** CSV 또는 부모 글의 근거가 없는데도 **기관의 치료 제공 가능 여부·적합성·지리적 인접성·미평가 사유 등을 사실처럼 단정**한 완결된 문장을 1개로 센다. 반복된 내용이라도 서로 다른 문장이라면 각각 1개로 센다.
- **집계하지 않음:** 기관에 대한 **질문**, `[추정]`·`[확인 필요]`로 불확실성을 명시한 정보, CSV에 실제 있는 값, 단순한 지역 탐색 결과 및 단순한 설명.
- **해석상 주의:** `지어낸 문장`은 해당 내용이 **현실에서 거짓이라고 검증됐다는 뜻이 아니라**, *이 시험에 제시된 CSV·부모 글로 뒷받침되지 않는 사실 단정*이라는 의미다. 최초 PDF 응답은 고치지 않고 원문 그대로 채점했다.

## 4. 표시 정확성 감점 판정 근거

### 4-1. 사례 1: 후보별 상태 표시 누락 (0/3점)

**PDF 2쪽:** Gemini는 기관명·시군구·동·주소·전화번호·치료분야에 **각 항목별 상태 표시를 붙이지 않았다.** 표 아래 참고사항에서 전체적으로 `기관명, 시군구·동, 주소, 전화번호는 ... [확인됨]`, `치료 분야는 ... [추정] 또는 [확인 필요]`라고 설명했다. 운영시간과 대기에는 `[확인 필요]`를 붙였다.

고정 기준은 **후보별 각 정보의 상태를 표시**하도록 요구한다. 일괄 설명만으로 어느 후보의 치료분야가 `[추정]`이고 `[확인 필요]`인지 구분할 수 없다.

- 후보 1: **0/1점** — 개별 표시 누락
- 후보 2: **0/1점** — 개별 표시 누락
- 후보 3: **0/1점** — 개별 표시 누락
- **합계: 0/3점.** 나머지 평가 항목 점수는 변경하지 않는다.

### 4-2. 사례 3: CSV에 있는 전화번호의 상태 표시 불일치 (2/3점)

- **PDF 7쪽, 후보 1·2:** 기관·주소·전화번호에 `[확인됨]`, 치료분야에 `[추정]`, 운영시간·대기에 `[확인 필요]`를 표시했다. **각 1/1점**.
- **PDF 7쪽, 후보 3:** 맘앤아이 아동발달 연구소의 전화번호는 CSV에 `054-000-0000`으로 기록돼 있는데 Gemini는 `054-000-0000 [확인 필요]`라고 표시했다. 고정 기준은 **CSV에 있는 전화번호에 `[확인됨]` 표시**를 요구하므로, 표시 정확성 항목에서는 **0/1점**이다.
- **결과:** 후보 1 **1/1**, 후보 2 **1/1**, 후보 3 **0/1** → **2/3점**. 기존 결과의 3/3점을 바로잡아 **총점 48/51 → 47/51점**으로 정정한다.
- **데이터 품질과 채점은 구별:** `054-000-0000`은 실제 연락처로 신뢰하기 어려운 형태이며 **실제 연결 가능 여부는 확인하지 못함**. Gemini가 현실적인 확인 필요성을 알린 것은 실무상 적절할 수 있으나, **이 시험의 고정 표시 규칙과 불일치한다**는 이유로만 감점한다. 해당 번호는 Gemini의 창작이 아니므로 `지어낸 문장 수`에는 넣지 않는다.

## 7. 재시험 시행 여부 및 증빙 한계

- **운영시간·대기기간을 확인된 사실처럼 만들어낸 문장:** 최초 답변 3건에서 확인하지 못함. 관련 정보는 대체로 `[확인 필요]` 또는 기관에 대한 질문으로 작성됨.
- **지침상 재시험 조건:** 운영시간·대기정보를 지어냈을 때 해당 사례만 프롬프트 수정 후 재시험. 위 조건에 해당하는 최초 답변이 발견되지 않아 **재시험은 시행하지 않음**. 이것은 미비한 프롬프트를 모두 수정했다는 뜻이 아님.
- **기타 근거 없는 단정 9문장:** 재시험 필수 조건과 별도로 집계함. 추가 개선 권고 사항으로만 기록한다.

- **실제 검증하지 않은 사항:** 센터 현재 운영 여부, 번호 연결 가능 여부, 희망 치료의 실운영·시간·대기 기간, 치료 적합성.
