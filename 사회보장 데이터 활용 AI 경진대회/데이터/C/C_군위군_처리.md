# C_군위군_처리

## 1. 배경

- 군위군은 2023년 7월 1일 경상북도에서 대구광역시로 편입되었다.
- 현재 기준(2026년)으로 대구 9개 + 경북 22개 = 31개 시군구로 분석한다.

## 2. 지도 처리

| 항목 | 처리 |
| --- | --- |
| 소속 | 대구광역시 군위군으로 표시 |
| 경계 파일 | 2023년 7월 이후 버전 사용 (군위군이 대구에 속한 버전) |
| 지도 주석 | "군위군은 2023년 7월 대구광역시로 편입되었으며, 이전 통계는 경상북도로 집계됨" |
| 분류 근거 | 등록 기관 1곳은 주소가 구미시이고 이용자·인력 0명. 군위군청 정보공개 회신(2026-11-13)도 관내 제공기관 "미해당", 대기자 0명 → A v3에서 '기관 없음'으로 분류(11/16) |

## 3. 2029년 추세 방법

### 3-1. 방법

- **11/7 팀 결정: 2020~2026년 9월 값 7개를 쓴다.** 처음에는 2014~2026년 13개를 썼으나, 2014~2019년 정체 구간 때문에 최근 증가세를 크게 낮게 잡아서 바꿨다(아래 3-3 비교).
- 시군구별 2020~2026년 **9월 값** 7개(지적·자폐성 아동 수 합계)에 단순 선형추세를 적용해 2029년 값을 추정한다.
- AI 예측이 아니라 현재 추세를 연장한 통계적 추정이다. 연도별 같은 달을 써 2026년 자료가 9월까지만 있는 문제를 피한다.
- 지역은 현재(2026년) 기준 31개로 맞춘다. 군위군은 시도와 관계없이 하나로 이어 붙이고, 경상북도로 집계된 2020~2022년 값도 대구 합계에 포함한다.
- 추정값이 음수면 0으로 바꾼다(이번 계산에서는 없음). (2014~2026년 계산 때는 울릉군 2014년 9월 행이 없어 0으로 두었음)
- 자료: `대구경북_발달장애아동_0-17세_시군구_월별_201312-202609.csv`

### 3-4. 주의할 점

- **최근 증가가 느려지는 중이다.** 실제 증가폭이 2023→2024년 +488명, 2024→2025년 +323명, 2025→2026년 +164명으로 줄고 있다. 직선은 연 382명을 가정하므로 2029년 값이 실제보다 높게 나올 수 있다. 제안서에는 "최근 추세가 이어지면 약 8,400명"처럼 조건을 붙여 쓴다.
- **점이 7개뿐이다.** 기간이 짧아 한두 해 값에 따라 결과가 크게 달라질 수 있다.
- **직선이 잘 맞지 않는 지역이 있다.** 성주·청송·군위는 R²가 0.2 미만이라 추세라고 보기 어렵다.
- **아동 수가 적은 지역은 흔들림이 크다.** 울릉(6명)·청송(16명)·군위(17명)·고령(20명)은 몇 명만 바뀌어도 증감률이 크게 달라진다.
- 추정값은 "공급 압박 가능성"을 보여주는 참고값이며, 필요한 치료실 수를 계산하는 데 쓰지 않는다.
