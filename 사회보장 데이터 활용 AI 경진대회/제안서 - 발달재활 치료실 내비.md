## 제안서 요약 (약 0.3쪽)

**한 줄 정의**
발달재활 바우처를 받은 부모에게는 아이 조건에 맞는 치료실 후보와 "전화해서 물어볼 질문"을 주고, 부모들이 확인한 결과를 모아 구청에는 치료 공백 지도를 주는 AI 서비스입니다.

**요약**
장애아동 부모는 바우처를 받아도 전국 2,949곳의 발달재활 제공기관 중 어디가 우리 아이에게 맞는지 알 방법이 없습니다. 공개된 정보는 기관명·주소·전화번호와 품질평가 정도이고, 치료 분야·운영시간·대기 정보는 없기 때문입니다.
이 서비스는 한국사회보장정보원의 사회서비스 제공기관 정보(오픈API), 전자바우처의 기관별 품질평가·이용 현황, 장애인등록 통계를 결합해 후보를 고릅니다. 공개 데이터로 알 수 없는 정보는 추측하지 않고 "확인 필요"로 표시한 뒤, AI가 기관에 물어볼 질문을 만들어 줍니다. 부모가 확인한 결과는 다음 부모의 추천과 구청의 공백 지도에 쌓여, 공개 데이터의 빈칸을 채웁니다.

**핵심 흐름 (그림 1개로 넣기)**

```
부모가 말로 상황 입력 → AI가 조건 추출 → 후보 3곳 + 확인/미확인 비교표
→ AI가 기관별 확인 질문 생성 → 부모가 전화로 확인하고 결과 입력
→ ① 다른 부모의 추천에 반영  ② 구청 공백 지도에 반영  ③ 추천 모델 학습
```

## 1. 제안 배경 및 아이디어 소개 (약 0.5쪽)

### 문제

**부모: 고를 정보가 없습니다**
- 발달재활서비스는 장애아동의 언어·인지·행동 발달을 돕는 바우처 사업입니다 (장애아동 복지지원법 제21조).
- 전국 0~17세 등록 발달장애 아동(지적·자폐성)은 72,029명이고, 0~17세 등록 장애아동의 77%입니다 (2026년 9월).
- 이 아이들이 고를 수 있는 제공기관은 2,949곳(2026년 11월)이지만, 어떤 치료를 하는지, 언제 하는지, 대기가 있는지는 공개되지 않아 부모가 일일이 전화해야 압니다.
- 그래서 부모는 입소문에 기대고, 다녀보고 맞지 않으면 처음부터 다시 찾습니다.

**대기가 일상입니다**
- 정보공개포털에서 "발달재활 대기"를 검색하면 최근 3개월 동안 시군구·읍면동이 만든 관련 행정문서가 876건 나옵니다. "대기자 명단 제출", "대기신청서 제출" 같은 문서입니다 (2026-10-28 검색. 검색어가 들어간 문서 수이므로 모두가 대기 문서는 아닙니다).

**지역 격차가 큽니다 (대구·경북 직접 분석)**
- 치료실이 아예 없는 곳이 2곳입니다. 경북 청송·울릉의 발달장애 아동 22명은 다른 시군으로 다녀야 합니다. 대구 군위군은 치료실이 1곳 있지만 이용자·치료사가 0명입니다.
- 경북 의성·상주·봉화는 치료실 1곳당 발달장애 아동이 45~53명으로, 대구 평균(16명)의 약 3배입니다.
- 치료사 1명당 이용자는 대구 10.1명, 경북 15.4명이고, 경북 영덕은 37.3명입니다.

**기관 품질도 고르지 않습니다**
- 2024년 발달재활서비스 첫 품질평가에서 전국 1,786곳 중 D등급 210곳(11.8%), F등급 60곳(3.3%)이 나왔습니다.

**구청: 어디가 부족한지 모릅니다**
- 지역별로 어떤 치료가 부족한지 알 수 있는 자료가 없어, 민원이 쌓인 뒤에야 압니다.

### 한 사람의 예시
맞벌이 부모 ○○씨의 5살 아이가 자폐 스펙트럼 진단을 받았습니다. 집 근처 치료실 두 곳은 대기가 6개월이었고, 토요일 수업이 되는 곳은 차로 40분 거리였습니다. 그곳을 석 달 다녔지만 아이와 맞지 않아 다시 처음부터 찾고 있습니다.

### 목적과 대상
- **목적:** 부모의 치료실 탐색 시간과 잘못된 선택을 줄이고, 지자체가 치료 공백을 미리 알게 합니다.
- **대상:**
  - 1차: 발달재활 바우처를 이용하는 부모
  - 2차: 시·군·구 바우처 담당 공무원, 한국사회보장정보원

### 결합 방식
시군구(1단계)와 읍면동(2단계) 단위로 묶습니다.

```
수요 (등록 장애아동 수, 연령·유형별)
  × 공급 (치료실 위치·동, 치료 분야)
  × 품질·이용 (2024 품질평가, 이용자 수, 제공인력 수)
  × 가까움 (같은 동 → 같은 시군구, 2단계에서 이동시간)
  = 부모용 후보 추천 + 구청용 공백 지수
```

| 운영시간·대기 | AI가 만든 확인 질문으로 부모가 직접 확인 → 결과를 날짜와 함께 저장 |
| 지역별 대기자 수 | 정보공개청구(2026-11-01, 사보원·대구시·경북도·복지부), 2단계에서 사보원 바우처 시스템 연계 |

- 6세 미만은 장애 등록 없이 의사 소견서로도 발달재활을 받을 수 있어, 등록 통계는 영유아 수요를 적게 잡습니다. 전자바우처 이용자 수로 보완합니다.
- 웹사이트 자동 수집(크롤링)은 하지 않습니다. 공공데이터포털 오픈API, 공식 통계·자료, 정보공개청구로만 데이터를 얻습니다.

## 3. AI 활용 방법 및 혁신성 (약 1쪽 · 배점 20점)

### ★ AI가 하는 일과 일반 프로그램이 하는 일

"AI가 장식 아니냐"는 질문에 답하기 위해 역할을 나눴습니다. 규칙으로 되는 일은 일반 프로그램이 하고, 규칙으로 안 되는 일만 AI가 합니다.

| 일반 프로그램이 하는 일 | AI가 하는 일 |
| --- | --- |
| 데이터 조회, 지역 필터 | ★ 부모가 말로 쓴 상황에서 조건 뽑기 |
| 가까움 계산 (같은 동·시군구) | 후보 점수 매기기 (1단계 규칙 → 2단계 학습) |
| 품질등급으로 후보 거르기 | ★ 기관별 확인 질문 만들기 |
| 비교표 칸 채우기 | 추천 이유를 쉬운 말로 설명하기 |
| 확인 결과 저장·집계 | 지역별 3년 수요 예측, 공백 지수 |

### 기능 1. ★ 말로 조건 입력
- 부모는 선택지를 고르거나, 말로 써도 됩니다.
  - 입력 예: "5살이고 말이 늦어요. 낯선 곳을 무서워하고, 평일은 어린이집 끝나고 4시 이후만 돼요. 토요일 오전도 괜찮아요."
  - AI가 뽑은 조건: 나이 5세 / 필요 영역 언어 / 아이 특성 낯가림 / 가능 시간 평일 16시 이후, 토요일 오전
- 뽑은 조건은 부모에게 다시 보여주고 고칠 수 있게 합니다.

### 기능 2. 후보 추천 (단계별)
- **1단계 (규칙 점수):** 지금 데이터로 계산할 수 있는 가까움(같은 동 → 같은 시군구)과 치료 분야 일치로 점수를 매깁니다. 운영시간은 공개 데이터에 없으므로, 시간 조건은 부모 확인으로 운영시간이 확인된 기관에만 더합니다. 품질등급은 점수에 넣지 않고, 아래처럼 후보를 거르는 데만 씁니다.
- **2단계 (학습형):** 부모의 1·3개월 뒤 결과("계속 다님 / 바꿈 / 그만둠")가 쌓이면, "3개월 뒤에도 계속 다닐 확률"을 예측하는 모델로 바꿉니다. 지도 API로 실제 이동시간도 넣습니다.
- **쏠림 방지:** 다른 부모들이 "대기 길다"고 확인한 기관이나 치료사 1명당 이용자가 많은 기관이 몰리면, 조건이 비슷한 다른 기관을 함께 보여줘 수요를 나눕니다.

**품질등급 쓰는 법**

| 등급 | 부모용 추천 | 구청 화면 |
| --- | --- | --- |
| A·B·C | 똑같이 취급 (등급으로 순위를 매기지 않음) | 표시 |
| D·F, 평가받았으나 등급 비공개 | 다른 후보가 없을 때만 추천 (F는 제외). 등급 비공개 기관은 D·F일 수 있다는 추정이라, 확인 전까지 조심스럽게 다루는 내부 규칙 | 컨설팅 대상으로 표시 |
| 평가 안 받음 | 불이익 없음 (신규 기관 보호) | 표시 |

부모에게 등급을 보여주지 않는 이유: 2024년 평가에서 A등급은 32.3%입니다. 등급을 보여주면 부모가 A등급 기관에만 몰려 대기가 더 길어지고, 지역 간 불균형이 커집니다.

### 기능 3. ★ 확인/미확인 구분 비교표
후보 3곳을 지도와 한 표로 보여주되, 정보마다 어디서 나왔는지 표시합니다.

| 항목 | 가 센터 | 나 센터 | 다 센터 |
| --- | --- | --- | --- |
| 위치 | 같은 동 ✅ 확인됨 | 같은 구 ✅ 확인됨 | 같은 구 ✅ 확인됨 |
| 언어치료 | 🔍 추정 (기관명) | ✅ 확인됨 (부모 확인 3건, 10월) | ❓ 확인 필요 |
| 토요일 운영 | ❓ 확인 필요 → 질문 1 | ✅ 확인됨 (부모 확인, 9월) | ❓ 확인 필요 → 질문 1 |
| 대기 | ❓ 확인 필요 → 질문 2 | ⚠️ 부모 확인: 2~3개월 (10월) | ❓ 확인 필요 → 질문 2 |
| 연락 | 📞 전화 · 🗺️ 지도 | 📞 전화 · 🗺️ 지도 | 📞 전화 · 🗺️ 지도 |

### 기능 4. ★ 기관별 확인 질문 만들기
AI가 아이 조건과 비교표의 "확인 필요" 칸을 보고, 기관마다 전화로 물어볼 질문을 만듭니다.
- 가 센터에 물어볼 것
  1. 토요일 오전에 언어치료 수업이 있나요?
  2. 지금 신청하면 대기는 얼마나 되나요?
  3. 낯가림이 심한 5살 아이를 맡아 본 치료사가 있나요?
  4. 바우처 지원금 외에 추가로 내는 비용이 있나요?
- 통화 뒤 부모가 답을 누르면("토요일 됨", "대기 3개월") 비교표가 바로 바뀌고, 다른 부모에게도 날짜와 함께 보입니다.

### 기능 5. ★ 첫 상담 체크리스트
기관을 정하고 첫 상담에 갈 때 챙길 것을 정리해 줍니다.
- 바우처 카드 결제 방법과 본인부담금
- 치료사 자격과 경력
- 치료 목표를 어떻게 정하고, 몇 달마다 평가하는지
- 결석·보강 규정, 부모 상담 시간

### 기능 6. 구청용 공백 지도와 3년 예측
- 지역별 등록 장애아동 수(2013년~ 월별 시계열)로 3년 뒤 수요를 예측하고, 치료실·치료사 수와 비교해 부족 지역을 찾습니다.
- 부모들이 "조건에 맞는 곳 없음"을 남긴 요청을 모아 보여줍니다. 예: "○○구 토요일 언어치료 요청 42건"

### ★ AI 안전 원칙
1. **AI는 확인 안 된 정보를 추측하지 않습니다.** 데이터에 없는 정보는 "확인 필요"로 표시하고, 질문으로 바꿉니다.
2. **추천은 탐색을 돕는 것이지, 치료가 맞는지 판정하는 것이 아닙니다.** 치료 방향은 전문가와 상담하도록 안내합니다.
3. **추천 이유는 데이터에 있는 내용으로만 씁니다.** LLM에는 기관 데이터와 확인 결과만 주고, 그 밖의 내용은 쓰지 못하게 합니다.
4. **부모 확인 결과에는 날짜를 붙입니다.** 오래된 정보는 다시 확인하라고 표시합니다.

## 4. 기존 서비스·연구와의 차별성 (약 0.5쪽 · 배점 15점)

| 비교 대상 | 무엇을 했나 | 우리와 다른 점 |
| --- | --- | --- |
| 2025 장려 「요양매칭플러스」 | 노인 요양시설 추천 | 대상이 장애아동. 확인 결과가 쌓여 데이터의 빈칸을 채우고, 공백 예측으로 이어짐 |
| 2026 우수 「플랜에이블」 | 성인 장애인 개인예산제 서비스 추천 | 성인 개인예산 사용법이고, 우리는 아동 발달재활 치료실 |
| 2020 최우수 「가배」 | 장애정보 기반 보조기기·서비스 큐레이션 | 보조기기 중심이고, 지역 공백 분석이 없음 |
| 사회서비스 전자바우처 「제공기관 검색」 | 지역별 기관 목록, 품질평가, 이용자 수 | 치료 분야·운영시간·대기가 없음. 조건 매칭, 확인 질문, 결과 학습, 공백 예측이 없음 |

**핵심 차별점 세 가지**
1. **모르는 것을 숨기지 않는 추천:** 확인된 정보와 확인 필요한 정보를 나누고, 확인할 질문까지 만들어 줍니다.
2. **부모가 쓸수록 데이터가 채워지는 구조:** 한 부모의 확인 결과가 다음 부모의 비교표를 채웁니다.
3. **개인 추천이 정책 근거로 이어지는 구조:** 부모들의 "못 찾음"이 모여 구청의 공백 지도와 예측이 됩니다.

발달재활 치료실 선택을 다룬 수상작은 없습니다.

## 7. 기대효과 및 ESG 가치 (약 0.3쪽 · 배점 5점)

- **국민 편익:** 부모의 탐색 시간, 확인 누락, 잘못된 선택이 줄고, 아이의 치료 공백이 짧아집니다.
